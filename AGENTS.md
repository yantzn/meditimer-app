# MediTimer agent instructions

Scope: this entire repository. These instructions are applicable to Codex and other agents that read `AGENTS.md`.

## Task protocol

1. Locate the `MEDI-` Jira work item; read its acceptance criteria and links to the SRS v0.4. If the task conflicts with the SRS, stop and report the discrepancy rather than silently changing medicine-related logic.
2. Before editing files, consult the rules for the affected area:
   - `.agents/rules/flutter-architecture.md`
   - `.agents/rules/medication-safety.md`
   - `.agents/rules/security.md`
3. Prefer a minimal diff on the current work branch. No secrets, patient records or autogenerated code without reviewing impact. Avoid introducing libraries outside the accepted P0 technical decision.
4. Add or update unit, widget and integration tests for behavior changes. Write failure cases before accepting success criteria.
5. Run applicable local checks in `docs/quality-gates.md`. When the Flutter app does not exist, explicitly say which checks could not run.
6. For reviews, use `.agents/skills/flutter-code-review/SKILL.md`, `security-review/SKILL.md`, `medication-safety-review/SKILL.md` and `test-design/SKILL.md` as relevant.
7. Summarize changes, executed commands, test evidence, unresolved risks and links to the Jira work item. Never claim to have executed checks that were not run.

## Non-negotiable invariants

- The app records facts; it **does not authorize medication**, calculate a recommended dose, infer active ingredients, diagnose dehydration or assert a medicine combination is safe.
- Medicine interval is set **explicitly by the caregiver in positive whole minutes per medication preset**, initially unset. It measures elapsed time from the **actual** recorded administration time.
- A past administration must remain recordable even when earlier than the configured interval; warn and capture context rather than suppressing actual history.
- Keep before-dose history checking separate from recording an already completed dose.
- P1 shows recent doses of **all** medicines for the child; only same-preset interval math is authoritative. P2 manually grouped related medicines must never be interpreted as expert-verified pharmacology.
- Do not erase or overwrite original administration events during corrections, sync conflicts or retries. Preserve auditability and idempotency.
- Offline recording must work; sync state must not misleadingly imply that another caregiver has definitely seen all records.
- No cross-family data access, even when a client crafts document paths or membership IDs.
- Critical/High safety or authorization findings block merge until fixed and reverified; AI findings are not medical/legal certification.
